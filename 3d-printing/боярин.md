# Боярин — эталон визуализации STL для 3D-печати

## Промпт
Используй загруженный STL-файл как единственный источник геометрии изделия. Покажи, как будет выглядеть готовая фигурка после FDM/3D-печати: только **внешняя непрозрачная поверхность**, без визуализации внутреннего заполнения (gyroid), стенок в разрезе, сетки треугольников или полупрозрачности. Не придумывай и не заменяй форму по названию файла. Сохрани исходные пропорции, одежду, черты лица, головной убор, обувь, основание и все реально присутствующие элементы. Материал — матовый непрозрачный пластик, условный бронзовый оттенок, мягкий студийный свет, нейтральный светлый фон, высокая читаемость деталей. Сделай **одну картинку из четырёх одинаково масштабированных ракурсов**: спереди, справа, сзади, слева; вся фигурка полностью в кадре, без обрезки. Ракурсы должны происходить из одной и той же геометрии STL, а не из четырёх независимых фантазийных генераций.

## Файл и параметры
- Исходник: Boyarin_140mm_wall2mm_gyroid40(20261021-124945).stl
- Габариты: примерно 65,7 × 55,2 × 140 мм
- Предположительно внутри смоделировано заполнение gyroid 40%; при рендере показывать только внешнюю оболочку.
- Эталонный файл результата в чате: boyarin_3d_print_four_views.png (четыре ракурса в одном PNG).
- Для точного повторения рендерить сам STL с отбором внешней поверхности; текстовый промпт не заменяет геометрический рендер.
