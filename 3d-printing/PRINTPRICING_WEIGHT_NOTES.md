# Техническая выжимка из чата 3D PrintPricing: масса 3D-моделей

Источник: экспорт Telegram-чата «3D PrintPricing» (messages.html, messages2.html), предоставленный пользователем, июль–август 2026. Сохранены только сведения, полезные для расчёта массы. Это не исходный код калькулятора и не подтверждение точности конкретного алгоритма.

## Факты из переписки
- В приложении для SLA вес модели отображается в граммах и вычисляется из объёма смолы с учётом её плотности (сообщение #45, 02.07.2026).
- Для SLA поддерживается импорт данных файлов слайсера и учёт объёма смолы, включая поддержки (сообщения #36 и #45).
- В версии 6.1.1 (11.08.2026) добавлена загрузка G-code/3MF с автоматическим извлечением граммов и времени печати для **одного** филамента; при нескольких филаментах автоматическая подстановка не выполняется (сообщение #1148).
- В каталоге моделей можно подставлять заранее сохранённую граммовку (сообщение #37); её нельзя считать измерением геометрии STL.

## Рабочие правила для расчётов (техническое обобщение)
1. Сначала определить источник: готовый G-code/3MF после слайсинга, геометрия STL/STEP или только габариты/изображение. Отмечать уровень точности.
2. **FDM:** для фактического расхода предпочитать оценку слайсера по конкретному профилю: материал, диаметр нити, периметры, верх/низ, заполнение и тип (например, gyroid), поддержки, brim/raft. Масса = длина экструдируемого прутка × площадь его сечения × плотность, либо сумма объёмов экструдируемого материала × плотность.
3. **SLA:** масса (г) = объём использованной смолы (мл = см³) × плотность смолы (г/см³); отдельно учитывать поддержки и технологические потери. Не приравнивать миллилитры граммам без плотности.
4. **Сплошной герметичный STL:** масса сплошной детали (г) = объём замкнутого тела (мм³) / 1000 × плотность (г/см³). Для полой/заполняемой FDM-модели эта формула не равна расходу при печати.
5. Нельзя умножать полный объём модели просто на 30% или 40% заполнения: внешние стенки, крышки, днище и поддержки имеют другой расход.
6. При нескольких материалах рассчитывать объём/массу каждого отдельно; учитывать purge/prime tower и отходы по данным слайсера.
7. Проверять единицы, размер и масштаб STL, водонепроницаемость/самопересечения, профиль печати; не объявлять расчёт по одному STL точным весом напечатанной модели.
8. В ответе выдавать массу изделия и, если применимо, расход материала с поддержками отдельными строками; фиксировать допущения.

## Связь с репозиторием
Дополняет `3d-printing/WEIGHT_CALCULATION.md`. Для точных FDM-оценок применять PrusaSlicer либо другой слайсер; для геометрического объёма — валидатор сетки или FreeCAD. Источник не содержит опубликованного алгоритма расчёта объёма STL.
