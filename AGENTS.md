# Правила расчётов

Актуальный калькулятор 3D-печати — `калькулятор последний.html` в корне этого репозитория, загруженный пользователем 9 октября 2026 года. При запросах расчёта читать текущую версию этого файла и использовать её формулы. Старые версии калькуляторов не использовать.

Дополнительные расходы, электронику, моделирование, сборку, шлифовку, покраску и смену цвета учитывать только по явному запросу пользователя для соответствующего заказа. Не переносить параметры между разными изделиями без указания пользователя.

В текущем файле себестоимость пластика 5 ₽/г, смолы 7,5 ₽/г; продажная ставка вводится вручную. При включённом НДС файл начисляет 22% на итоговую цену. Не подменять эту логику старыми фиксированными тарифами с НДС. Если пользователь задаёт цену уже с НДС, не начислять налог повторно и явно указать способ ввода ставки.

Для каждого расчёта указывать материал, расход на изделие, тираж, продажную ставку, скидку и дополнительные расходы (если запрошены). Отличать измеренный объём STL от предварительных оценок расхода с заполнением и поддержками.
